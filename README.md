# HEXRUSH

Juego infinito estilo Super Hexagon. Hecho por Jose Casanova.

## Publicar en GitHub Pages
1. Sube todos los archivos de esta carpeta a la raíz del repositorio (todo suelto, sin carpetas).
2. Settings → Pages → Branch: `main` / `(root)` → Save.
3. Abre `https://TU-USUARIO.github.io/TU-REPO/` e instala la app desde el navegador.

Al cambiar archivos, sube el número de `CACHE` en `sw.js` para que se actualice la app instalada.
